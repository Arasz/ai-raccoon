# Write to the user in Simplified Technical English

When you write a response, a report, a status update, a question or a hand-back to the user, use the `simplified-technical-english` skill. It adapts the ASD-STE100 writing rules to user-agent communication: one meaning for each word, short sentences, active voice, one instruction for each step, and warnings before the step they apply to. Code, commands, paths, identifiers and quoted error text stay exactly as they are.
