# Run what you changed; the pipeline runs the rest

Run the build and the tests your change touches, and let the pipeline run everything else — a full local sweep buys no coverage the pipeline does not already have and spends the same time twice. The obligation that trade creates is to know your new tests are inside what the pipeline actually runs: wherever it selects a subset — tags, markers, paths, suites, globs — a test outside the selection is invisible to it and rides through a green run, so confirm membership using the project's own selection mechanism instead of assuming some default sweeps everything up. The cost is that a failure surfaces after a push rather than before it, which is the trade and not an oversight: it holds only if you push early and read what the pipeline reports rather than assuming green. Tell any agent you dispatch the same thing — a delegated brief asks for a full local run out of habit.
