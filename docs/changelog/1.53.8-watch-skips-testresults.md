# 1.53.8: watches skip `TestResults` directories

Fix release.

- A directory named `TestResults` is now skipped by watches and `memory_ingest_directory`, the
  same way `bin` and `obj` are. It is where `dotnet test` and Visual Studio write test logs and
  results, and one 50 MB log there had been ingested as 5,811 rows on the author's bank, each one
  embedded.
- Banks that already hold files from a `TestResults` directory drop them, and their fingerprints,
  on the first watch catch-up scan after the upgrade, with no command needed.
