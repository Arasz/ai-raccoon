# 2.8.0: AiRaccoon runs on .NET 11

Platform release. **The tool needs the .NET 11 runtime.** It does not start on a machine that has only .NET 10. See [Breaking changes](../reference/breaking-changes.md).

- Every project targets `net11.0` and builds with SDK 11.0.100.
- Async methods compile as runtime-async (`<Features>runtime-async=on</Features>`). The runtime runs them without a compiler-generated state machine. `new StackTrace()` and profiler async stacks show fewer frames. Exception stack traces do not change.
- NuGet packages move to their current releases: Microsoft.Extensions and Microsoft.Data.Sqlite 11.0.0, ModelContextProtocol 2.4.0, OpenTelemetry 1.21.0, DotNext 6.12.1, AWSSDK.S3 4.1.0, OpenAI 2.15.0.
- Deferred: Microsoft.ML.Tokenizers 3.0 (#943), ONNX Runtime 1.31.1 (#944), System.CommandLine 3.0 (#946).

Ships #942. [ADR-0145](../adr/0145-target-dotnet-11-with-runtime-async.md)
