# 1.57.5: the file watcher ignores directory-name notifications

Fix release. No tool schema or settings changes.

- File watchers no longer subscribe to directory-name notifications; the watched filter is
  `FileName | LastWrite`. A directory's own event had nothing to digest — the ingest path returns
  for any directory — so it only added events to the watcher's buffer, the same buffer a change
  burst overflows. This trims directory churn (build output, `.git`, package managers) on Windows,
  Linux and macOS, where the runtime honours the same directory/file split.
- The one visible change: deleting or renaming a directory clears the old-path rows at the next
  reconcile (within 5 minutes) rather than immediately at the directory event. A file-level create,
  change, delete or rename still digests live, and no data is lost — the periodic reconcile removes
  rows for files gone from disk and re-ingests files at their new paths.
