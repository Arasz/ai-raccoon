# 1.53.12: `repair chunk-index` survives a partition vanishing mid-pass

Fix release.

- `repair chunk-index` (dry run or `--apply`) no longer crashes the server with
  `ArgumentOutOfRangeException` when a chunk group disappears while the pass is walking its group
  list — the list is a snapshot and the walk re-chunks files for minutes on a live bank. A group
  whose rows are gone by its turn is skipped (there is nothing to repair), and the report's groups
  count now covers only the groups the pass actually examined (#800).
- A chunk group whose context key is NULL — a row with no project id in a non-shared scope — is now
  found by the pass and repaired like any other. Its key compared with `=` matched nothing
  (`NULL = NULL`), so the pass crashed on the empty lookup the same way (#800).
