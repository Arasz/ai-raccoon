# 1.55.7: `serve` start split into bank preparation and host lifetime

Refactor release. No behaviour, output or exit code changes.

- `NodeRunner.StartHttpMcpServer` shrinks from 50 lines to 27. The checks that ready the bank
  before the listener binds move into `PrepareBankAsync`:
  - the key resolves
  - the key opens the bank
  - the embedding engines are available
  - vec0 matches their dimensions
- `StartHttpMcpServer` keeps only the host's lifetime: start, print the bound URL, wait for
  shutdown, and report an address-in-use bind.
- The preparation still runs inside the same `try` block, so the host is disposed on every exit as
  before.
