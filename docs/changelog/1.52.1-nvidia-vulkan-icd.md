# 1.52.1: WebGPU finds NVIDIA GPUs in containers that omit the Vulkan manifest

Fix-only release. Decision: [ADR-0115 amendment](../adr/0115-bundle-onnxruntimes-webgpu-core-for-windows-and-linux-x64.md#amendment-2026-09-25-nvidia-containers-without-an-icd-manifest).

- Many NVIDIA GPU containers (Lightning AI, and others built on NVIDIA's container toolkit) mount the
  Vulkan driver, `libGLX_nvidia.so.0`, without the JSON manifest that tells the Vulkan loader about
  it. WebGPU then found no adapter and the bundled engine ran on the CPU.
- On Linux, when that driver is present and no manifest or `VK_*` driver variable reaches the loader,
  the tool now writes a manifest to `$TMPDIR/ai-raccoon/nvidia_icd.json` and adds it for its own
  process only (`VK_ADD_DRIVER_FILES`). Nothing in your home directory or system Vulkan
  configuration changes.
- Measured on a Lightning AI Tesla T4: sessions now land on `WebGPU` with the CPU's vectors; before,
  they fell back to the CPU. Hosts that already have a manifest are unaffected.
