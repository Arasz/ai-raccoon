# 1.52.2: a session opened before a tool update restarts the new server

Fix-only release. Decision: [ADR-0116](../adr/0116-server-exits-when-its-install-is-replaced.md).

- Since 1.52.1 the server exits once `dotnet tool update -g ai-raccoon` deletes its install. A proxy
  started before the update resolved its own executable to the deleted versioned path, so it could not
  start the new server; that session lost memory until another session or a host restart started one.
- When the proxy's own executable is gone, it now starts the server through the dotnet global-tool
  shim (`~/.dotnet/tools/ai-raccoon`), then `ai-raccoon` on `PATH`, and refuses as before only when
  neither exists. It logs event 693 naming the missing path and the fallback used.
