# 1.53.1: `settings model device --help` lists coreml and fits on screen

Fix release.

- `ai-raccoon settings model device --help` now names every device, `coreml` included, in one
  short line. The 1.53.0 text left `coreml` out, ran to five wrapped lines, and cited ADR numbers,
  which help text must not. The argument's `<auto|gpu|cpu|mlx|cuda|coreml>` placeholder is now
  built from the list of accepted devices, so a new device appears in help without a hand edit.
- `scripts/device-benchmark.py` measures time to completion, SoC and whole-system energy, and
  memory for each embedding device on one corpus, so results from different Macs compare.
