# 2.7.0: MCP dispatch delay is visible in performance metrics

Feature release.

- `get_engine_statistics` reports `mcp.dispatch.delay_ms` for each HTTP tool call. Compare it with tool duration and `search.*` timings to locate time before MCP tool dispatch.
- `get_engine_statistics` reports `mcp.request.duration_ms` under `__self_metrics__`. It measures each HTTP POST through response completion, including requests that do not call a tool.
- The dispatch measurement has no caller-controlled tags. It does not claim to isolate a queue.

Ships #940.
