# 1.55.6: `serve --restart` cycle split into settle and stop

Refactor release. No behaviour, log or outcome changes.

- `ServerRestart.CycleAsync` shrinks from 54 lines to 17. It now reads as the cycle's three phases.
  `SettleBeforeIdentifyAsync` covers the probe and the identity proof. The identify step stays in
  `CycleAsync`. `StopAsync` covers the token read, the shutdown request and the port wait. The
  proof still comes before anything else is asked of the listener (ADR-0106 D5).
- A new unit test class, `ServerRestartOutcomeTests`, pins every restart outcome together with the
  requests sent to reach it. Before this, only the unproven-before-no-token ordering had a unit test.
