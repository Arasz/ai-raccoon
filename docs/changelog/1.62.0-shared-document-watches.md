# 1.62.0: Shared document watches

Documents outside a repository can now use the built-in `shared` project ID. Configure its
path scope and watch enablement, then run `ai-raccoon watch add shared /absolute/documents`.
No project ID needs to be minted. Watched and explicitly ingested documents appear in every
project's default memory search in the same bank.

Direct search, get, list and stats accept `shared`. Its search accepts `all` or `shared`;
ordinary project-only searches remain private. The target handles supported document formats,
with code skipped. Reserved-target notes, custom labels, workspaces and promotion operations
are refused explicitly. Ordinary projects retain their existing promotion workflow.

File changes, rename, deletion and restart catch-up preserve shared visibility. Removing a
watch retains indexed content. Legacy private `shared` owners and unactivated legacy watches
are refused, while ownership conflicts roll back a document's new chunks without advancing its
fingerprint. Shared cannot be aliased or retired by project-ID repair.
