# 1.53.6: a note repaired before its rows had positions now repairs too

Fix release.

- 1.53.5 put every source-citing note back in text order, except one shape: a note whose rows
  had never been positioned (still at the internal "unknown" marker) was left untouched, because
  the repair only moves positions it already knows. The very next maintenance step then filled
  those rows in id order, which could still land an old note's opening chunk last.
- Unknown positions are now given a place, in the order the bank already holds them, before a
  note's text order is checked. A note like that now comes out in text order too.
- Existing banks repair themselves again on the first maintenance pass after this upgrade, with
  no manual step, even if the earlier repair already ran and stamped itself done (#784).
