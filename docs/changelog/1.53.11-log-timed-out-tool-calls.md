# 1.53.11: a timed-out tool call says what timed out

Fix release.

- When a client gives up on a tool call and cancels it, the server now logs one warning (event 914,
  or 915 when the tool has no query) naming the tool, how long it ran and, for a search, the length of
  its query as a raw number — for example
  `"memory_search" timed out after 19687 ms (query of 4181 chars): the caller cancelled it`. Before,
  the only record was the SDK's "request handler failed" warning with a `TaskCanceledException`
  stack, which named neither the call nor the query.
