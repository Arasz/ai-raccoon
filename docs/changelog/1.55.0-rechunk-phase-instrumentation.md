# 1.55.0: the re-chunk phase's duration and group count are observable

Instrumentation release: no behaviour change — every bank re-chunks exactly as before.

- Event 448 ("Chunk-budget rebudget") now ends with the phase's wall-clock duration, e.g.
  `... 0 terminal in 00:05:05.5000000`, so a migration's re-chunk time is visible in the log and
  not only its counts.
- Two new internal series record one sample per rebudget pass: `chunk.rechunk.duration_ms`
  (histogram, milliseconds) and `chunk.rechunk.groups` (histogram, groups replaced).
  `memory_performance` reports them like the `drain.*` and `job.*` families.

The measurement exists because config D's 1022-token bank migration landed without it — the
follow-up named in [1.54.0](1.54.0-config-d-chunk-budgets.md).
