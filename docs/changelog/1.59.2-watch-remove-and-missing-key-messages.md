# 1.59.2: `watch remove` says when nothing was watched; a missing encryption key is named

Fix release. `memory_watch_remove`'s result gains an additive `removed` field; no settings changes.

- `ai-raccoon watch remove <project-id> <path>` on a path with no registered watch printed
  `removed: <path>` as if it had removed one. It now prints `not watched: <path> (nothing removed)`
  and still exits 0. `memory_watch_remove` and the CLI's `/watch` endpoint report `removed: false`
  in that case and `removed: true` when a registration was deleted.
- Opening an encrypted bank with no key resolved — an env-keyed bank with `AIRACCOON_DB_PASSPHRASE`
  unset — surfaced the raw `SQLite Error 26: 'file is not a database'` from `encryption show`,
  `serve` and other bank-opening commands, and `doctor` reported "wrong key or corrupt bank". When
  the bank's key verifier sidecar is present they now say the bank is encrypted and no key was
  resolved, naming `AIRACCOON_DB_PASSPHRASE`, and exit 20 (`Key.Unresolved`). A bank without a
  verifier is reported as before, so a corrupt unencrypted bank is still `Bank.Corrupted`.
