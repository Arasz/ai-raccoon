# 2.5.1: a watcher overflow during a scan is no longer lost until the heal

Fix release.

- An overflow that arrived while its watch was scanning joined that scan, which may already have
  passed the lost change, so the change waited for the 5-minute heal. The rescan now waits for the
  running scan to end and then runs.
- An overflow no longer queues a scan for a watch stopped after repeated failures, matching the heal.
