# 1.58.1: SQLite3 Multiple Ciphers 2.6.1 and the upstream pool fix

Dependency release. Ships #PR. No tool schema or settings changes.

- The bundled SQLite engine moves to SQLite3 Multiple Ciphers 2.6.1, which ships SQLite 3.54.0
  (it was 2.4.0 and SQLite 3.53.4). The default cipher (ChaCha20-Poly1305) and the file format do not
  change. Banks encrypted by earlier releases open, read, write and rekey as before, with a
  passphrase or a raw `x'…'` key and in WAL mode.
- Microsoft.Data.Sqlite.Core moves to 10.0.13, which fixes the pooled-connection race that 1.57.6
  worked around (dotnet/efcore#39012). The process-wide lock around pool checkouts is gone, so
  concurrent bank opens no longer wait on each other. A failed pragma still closes its connection.
  [ADR-0131](../adr/0131-serialize-pooled-sqlite-opens.md)
