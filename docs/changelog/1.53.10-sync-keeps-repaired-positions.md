# 1.53.10: sync keeps the chunk positions `repair chunk-index` kept

Fix release.

- On a bank that uses cloud sync, `memory_sync` no longer undoes `repair chunk-index --apply`. The
  sync renumbered every file's chunks after merging and treated a chunk marked "position unknown"
  as one it had just received, so it gave those chunks positions again and closed the gaps the
  repair had left. Now it positions only chunks it actually received from the other machine, after
  the file's existing chunks, and leaves everything else where the repair put it (#796).
- A sync that deletes a chunk still closes the gap it leaves, as before.
