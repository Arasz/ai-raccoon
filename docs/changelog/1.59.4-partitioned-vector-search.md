# 1.59.4: vector search reads only its own context

Performance fix. No tool schema or settings changes.

- `memory_search` and code search read only the searched context's vectors again (ADR-0133).
  Since ADR-0068 every vector search read and decrypted every project's vectors, outside SQLite's
  page cache, which made concurrent searches kernel-bound. On a copy of a 1 GB bank one search
  went from 0.23 s to 0.10 s and 20 concurrent searches from 3.94 s to 1.21 s.
- The first start after the update rebuilds the three vector tables and vacuums the bank once;
  on a 1 GB bank expect it to take a little longer than usual. The bank file grows by about 5%.
