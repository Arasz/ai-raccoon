# 2.2.0: query hits carry their entry kind, and the 2.x review fixes

PR #916 reviews 2.0.0, 2.0.1 and 2.1.0 (record:
[2026-10-23-2x-release-review.md](../work/2026-10-23-2x-release-review.md)) and ships what it
found.

## New

Every memory-corpus hit in a `query` result now carries `entryKind`: `memory`, `file`, or `none`
for a row that declares no kind. 2.1.0 made `get_entry` require an `entryType` but gave a query
result nothing to fill it from; pass the hit's `entryKind` straight through. The field is
additive: no existing field changed.

## Fixed

- `set_memory_ttl` with no `ttlDays` clears a TTL on an entry of any kind in the project. 2.1.0
  refused clearing a File entry's TTL while cleanup still honoured a TTL stored before 2.1.0, so
  such a TTL could neither be removed nor stopped. Setting a TTL stays Memory-only.
- Setting a TTL on a File entry is refused as `not-a-memory-entry` instead of `unknown-hash`. A
  hash from another project still reads as `unknown-hash`.
- `entryType=memory,file` applies no kind filter to memory hits, as ADR-0141 states, so it
  returns the same memory-corpus rows as the default `memory,code,file`, unclassified rows
  included. `memory` or `file` alone still selects declared rows only.
- The reserved project name `shared` is refused by the registry itself, so the HTTP and CLI
  register paths refuse it too (HTTP answers 400). Before, only the MCP tool refused it, and a
  project registered under that name through another path blocked shared publishing. The MCP
  refusal now reads `reserved-name: …` instead of `invalid-argument: reserved-name: …`.
- `get_quality_report` takes its default 7-day window from the server's clock in the service,
  not from the wall clock in the tool.

## Tests

- Two Nightly tests red since 2.0.1 and 2.1.0 are fixed: `ProxyForwardTests` still expected an
  unknown tool to throw, and `BackendLaunchIdentityProofE2ETests` called `get_entry` without
  `entryType`. Nightly runs only with the `run-nightly-gates` label; none of the release PRs
  carried it.
- New coverage for the doctor's kind lines, `EntryTypeParameter.Single(None)`, and a sweep of a
  historical File TTL; the env-gated typed-partition probes report skipped instead of passed.

Deferred structural follow-ups are tracked in #917.
